GolFlash SDK 58 - Proyecto informativo sin apuestas ni dinero.

Requisitos: Node.js >=22.13.0 y Expo Go SDK 58.

En PowerShell desde esta carpeta:
 npm install
 npx expo install --fix
 npx expo start --clear

Si falla la red, usar npx expo start --tunnel --clear.

Los partidos son datos de demostración, no resultados reales.
